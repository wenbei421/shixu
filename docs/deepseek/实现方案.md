# Tauri 中注入 DeepSeek 网页的 JavaScript 脚本方案

当前仓库 `ai-fzx/deepseek-skills` 原本通过：

```text
Node.js + Playwright + Chrome CDP
```

实现 DeepSeek 网页自动化。

改成 Tauri + Rust 后，建议保留原项目中的核心逻辑：

```text
定位输入框
  ↓
注入提示词
  ↓
点击发送
  ↓
监听回复 DOM
  ↓
判断生成完成
  ↓
提取最终结果
```

但是执行方式改成：

```text
Rust 创建 DeepSeek WebView
  ↓
Rust 使用 webview.eval() 注入 JavaScript
  ↓
JavaScript 操作 DeepSeek 页面
  ↓
JavaScript 通过 Tauri Command 将结果回传 Rust
```

---

## 一、推荐的注入脚本结构

不要把全部逻辑直接写在 `commands.rs` 中，建议拆成：

```text
src-tauri/
└── src/
    ├── main.rs
    ├── commands.rs
    ├── deepseek.rs
    └── injected_script.rs
```

职责如下：

| 文件 | 作用 |
|---|---|
| `main.rs` | 创建 Tauri 应用、注册 Command |
| `commands.rs` | 接收 DeepSeek 页面回传的事件 |
| `deepseek.rs` | 创建 WebView、注入脚本 |
| `injected_script.rs` | 保存和生成 JavaScript |

---

# 二、任务执行流程

每次执行一段提示词时，建议按以下流程执行：

```text
1. 创建或复用 DeepSeek WebView
2. 等待页面完成加载
3. 检查是否登录
4. 可选：点击新建对话
5. 保存当前页面回复快照
6. 注入提示词
7. 点击发送按钮
8. 使用 MutationObserver 监听页面变化
9. 提取最后一条 AI 回复
10. 判断回复是否稳定
11. 将最终结果回传 Rust
12. Rust 将结果返回 Vue
```

注意：

> 不要直接读取 `document.body.innerText`，否则会把历史会话、用户输入、按钮文本等内容一起提取出来。

# 三、Tauri WebView 创建代码

## `deepseek.rs`

```rust name=src-tauri/src/deepseek.rs
use tauri::{
    AppHandle,
    Manager,
    WebviewUrl,
    WebviewWindow,
    WebviewWindowBuilder,
};

const DEEPSEEK_URL: &str = "https://chat.deepseek.com/";

pub fn ensure_deepseek_window(
    app: &AppHandle,
) -> Result<WebviewWindow, String> {
    if let Some(window) = app.get_webview_window("deepseek-web") {
        window
            .show()
            .map_err(|e| format!("显示 DeepSeek 窗口失败: {e}"))?;

        return Ok(window);
    }

    let url = DEEPSEEK_URL
        .parse()
        .map_err(|e| format!("DeepSeek URL 解析失败: {e}"))?;

    let window = WebviewWindowBuilder::new(
        app,
        "deepseek-web",
        WebviewUrl::External(url),
    )
    .title("DeepSeek")
    .inner_size(1200.0, 850.0)
    .resizable(true)
    .visible(true)
    .build()
    .map_err(|e| format!("创建 DeepSeek WebView 失败: {e}"))?;

    Ok(window)
}
```

这里的 `deepseek-web` 是 WebView 窗口名称，后续 Rust 可以通过它获取网页窗口：

```rust
let window = app
    .get_webview_window("deepseek-web")
    .ok_or_else(|| "DeepSeek WebView 不存在".to_string())?;
```

# 四、注入脚本的完整实现

## `injected_script.rs`

下面的脚本实现：

- 查找 DeepSeek 输入框；
- 注入提示词；
- 触发 `input` 事件；
- 查找发送按钮；
- 没有发送按钮时使用 Enter；
- 监听 DOM 变化；
- 读取最后一条 AI 回复；
- 判断是否仍在生成；
- 连续两次内容不变后判断完成；
- 将事件回传给 Rust。

```rust name=src-tauri/src/injected_script.rs
use serde_json::to_string;

/// 生成 DeepSeek 网页任务脚本
pub fn build_task_script(
    task_id: &str,
    prompt: &str,
) -> Result<String, String> {
    let task_id_json = to_string(task_id)
        .map_err(|e| format!("task_id 序列化失败: {e}"))?;

    let prompt_json = to_string(prompt)
        .map_err(|e| format!("prompt 序列化失败: {e}"))?;

    Ok(format!(
        r#"
(() => {{
    const taskId = {task_id_json};
    const prompt = {prompt_json};

    if (window.__DEEPSEEK_TASK_RUNNING__) {{
        console.warn('[DeepSeek] 已有任务正在执行');
        return;
    }}

    window.__DEEPSEEK_TASK_RUNNING__ = true;

    const inputSelectors = [
        'textarea[placeholder]',
        '#chat-input',
        'textarea',
        '[contenteditable="true"]'
    ];

    const replySelectors = [
        '.ds-markdown',
        '[class*="markdown"]',
        '[data-role="assistant"]',
        '[class*="message-content"]'
    ];

    const stopSelectors = [
        'button[aria-label*="stop"]',
        'button[aria-label*="Stop"]',
        'button[aria-label*="停止"]',
        'button[title*="stop"]',
        'button[title*="Stop"]',
        'button[title*="停止"]'
    ];

    let observer = null;
    let completed = false;
    let previousText = '';
    let stableCount = 0;

    function invokeRust(type, payload = {{}}) {{
        const event = {{
            taskId,
            type,
            ...payload
        }};

        const serializedEvent = JSON.stringify(event);

        try {{
            // Tauri v2 开启 withGlobalTauri 后使用该接口
            if (
                window.__TAURI__ &&
                window.__TAURI__.core &&
                window.__TAURI__.core.invoke
            ) {{
                window.__TAURI__.core.invoke(
                    'receive_deepseek_page_event',
                    {{
                        event: serializedEvent
                    }}
                );

                return;
            }}

            // 兼容部分 Tauri 配置
            if (
                window.__TAURI_INTERNALS__ &&
                window.__TAURI_INTERNALS__.invoke
            ) {{
                window.__TAURI_INTERNALS__.invoke(
                    'receive_deepseek_page_event',
                    {{
                        event: serializedEvent
                    }}
                );

                return;
            }}

            console.error(
                '[DeepSeek] Tauri IPC 不可用',
                event
            );
        }} catch (error) {{
            console.error(
                '[DeepSeek] 回传 Rust 失败',
                error
            );
        }}
    }}

    function isVisible(element) {{
        if (!element) {{
            return false;
        }}

        const style = window.getComputedStyle(element);

        return (
            element.offsetParent !== null &&
            style.display !== 'none' &&
            style.visibility !== 'hidden'
        );
    }}

    function findInput() {{
        for (const selector of inputSelectors) {{
            const elements = document.querySelectorAll(selector);

            for (const element of elements) {{
                if (
                    isVisible(element) &&
                    !element.disabled &&
                    !element.readOnly
                ) {{
                    return element;
                }}
            }}
        }}

        return null;
    }}

    function findSendButton() {{
        const selectors = [
            'button[type="submit"]',
            'button[aria-label*="send"]',
            'button[aria-label*="Send"]',
            'button[aria-label*="发送"]',
            'button[title*="send"]',
            'button[title*="Send"]',
            'button[title*="发送"]',
            '[class*="send-button"]',
            '[class*="sendButton"]'
        ];

        for (const selector of selectors) {{
            const elements = document.querySelectorAll(selector);

            for (const element of elements) {{
                if (
                    isVisible(element) &&
                    !element.disabled
                ) {{
                    return element;
                }}
            }}
        }}

        return null;
    }}

    function setInputValue(input, value) {{
        input.focus();

        if (input instanceof HTMLTextAreaElement) {{
            const setter = Object.getOwnPropertyDescriptor(
                HTMLTextAreaElement.prototype,
                'value'
            )?.set;

            if (setter) {{
                setter.call(input, value);
            }} else {{
                input.value = value;
            }}
        }} else if (input instanceof HTMLInputElement) {{
            const setter = Object.getOwnPropertyDescriptor(
                HTMLInputElement.prototype,
                'value'
            )?.set;

            if (setter) {{
                setter.call(input, value);
            }} else {{
                input.value = value;
            }}
        }} else {{
            input.textContent = value;
        }}

        input.dispatchEvent(new InputEvent('input', {{
            bubbles: true,
            inputType: 'insertText',
            data: value
        }}));

        input.dispatchEvent(new Event('change', {{
            bubbles: true
        }}));
    }}

    function hasStopButton() {{
        for (const selector of stopSelectors) {{
            const elements = document.querySelectorAll(selector);

            for (const element of elements) {{
                if (isVisible(element)) {{
                    return true;
                }}
            }}
        }}

        return false;
    }}

    function getReplyElements() {{
        const result = [];
        const seen = new Set();

        for (const selector of replySelectors) {{
            const elements = document.querySelectorAll(selector);

            for (const element of elements) {{
                if (!seen.has(element)) {{
                    seen.add(element);
                    result.push(element);
                }}
            }}
        }}

        return result;
    }}

    function getLastReplyText() {{
        const elements = getReplyElements();

        if (elements.length === 0) {{
            return '';
        }}

        // 优先取最后一个元素
        for (let index = elements.length - 1; index >= 0; index--) {{
            const text = (
                elements[index].innerText ||
                elements[index].textContent ||
                ''
            ).trim();

            if (text.length > 0) {{
                return text;
            }}
        }}

        return '';
    }}

    function submitPrompt() {{
        const input = findInput();

        if (!input) {{
            invokeRust('error', {{
                error: 'INPUT_NOT_FOUND',
                message: '未找到 DeepSeek 输入框'
            }});

            cleanup();
            return false;
        }}

        setInputValue(input, prompt);

        // 优先点击发送按钮
        const sendButton = findSendButton();

        if (sendButton) {{
            sendButton.click();

            invokeRust('submitted', {{
                method: 'button'
            }});

            return true;
        }}

        // 找不到发送按钮时使用 Enter
        input.dispatchEvent(new KeyboardEvent('keydown', {{
            key: 'Enter',
            code: 'Enter',
            keyCode: 13,
            which: 13,
            bubbles: true,
            cancelable: true
        }}));

        input.dispatchEvent(new KeyboardEvent('keyup', {{
            key: 'Enter',
            code: 'Enter',
            keyCode: 13,
            which: 13,
            bubbles: true,
            cancelable: true
        }}));

        invokeRust('submitted', {{
            method: 'enter'
        }});

        return true;
    }}

    function cleanup() {{
        if (observer) {{
            observer.disconnect();
            observer = null;
        }}

        window.__DEEPSEEK_TASK_RUNNING__ = false;
    }}

    function checkReply() {{
        if (completed) {{
            return;
        }}

        const text = getLastReplyText();
        const generating = hasStopButton();

        if (text) {{
            if (text === previousText) {{
                stableCount += 1;
            }} else {{
                stableCount = 0;
                previousText = text;
            }}
        }}

        invokeRust('progress', {{
            text,
            generating,
            stableCount
        }});

        // 必须满足：
        // 1. 已经有回复文本
        // 2. 页面没有停止生成按钮
        // 3. 文本连续两次没有变化
        if (
            text.length > 0 &&
            !generating &&
            stableCount >= 2
        ) {{
            completed = true;

            invokeRust('completed', {{
                result: text
            }});

            cleanup();
        }}
    }}

    invokeRust('started', {{
        prompt
    }});

    // 先等待页面结构稳定，再提交
    setTimeout(() => {{
        if (!submitPrompt()) {{
            return;
        }}

        observer = new MutationObserver(() => {{
            checkReply();
        }});

        observer.observe(document.documentElement, {{
            subtree: true,
            childList: true,
            characterData: true,
            attributes: true
        }});

        // MutationObserver 之外再增加定时检查，
        // 防止某些页面更新没有触发预期 DOM 事件
        const timer = setInterval(() => {{
            if (completed) {{
                clearInterval(timer);
                return;
            }}

            checkReply();
        }}, 1000);

        setTimeout(() => {{
            clearInterval(timer);
        }}, 180000);
    }}, 1000);
}})();
"#,
        task_id_json = task_id_json,
        prompt_json = prompt_json,
    ))
}
```

# 十五、为什么要使用 `serde_json::to_string`

不要这样拼接提示词：

```rust
let script = format!(
    "const prompt = '{}';",
    prompt
);
```

因为用户可能输入：

```text
他说：'你好'
```

或者：

```text
第一行
第二行
```

甚至输入 JavaScript 特殊字符，导致注入脚本语法错误。

正确方式是：

```rust
let prompt_json = serde_json::to_string(prompt)?;
```

生成：

```javascript
const prompt = "用户输入的内容";
```

这样可以正确处理：

- 单引号；
- 双引号；
- 换行；
- 反斜杠；
- JSON 字符；
- 中文；
- Markdown；
- 代码片段。

```rust name=src-tauri/src/commands.rs
use serde::Deserialize;
use tauri::{AppHandle, Emitter};

use crate::models::DeepSeekPageEvent;

#[derive(Debug, Deserialize)]
pub struct PageEventRequest {
    pub event: String,
}

#[tauri::command]
pub fn receive_deepseek_page_event(
    app: AppHandle,
    payload: PageEventRequest,
) -> Result<(), String> {
    let event: DeepSeekPageEvent =
        serde_json::from_str(&payload.event)
            .map_err(|e| format!("解析页面事件失败: {e}"))?;

    match event.event_type.as_str() {
        "started" => {
            app.emit("deepseek-task-started", &event)
                .map_err(|e| format!("发送 started 事件失败: {e}"))?;
        }

        "submitted" => {
            app.emit("deepseek-task-submitted", &event)
                .map_err(|e| format!("发送 submitted 事件失败: {e}"))?;
        }

        "progress" => {
            app.emit("deepseek-task-progress", &event)
                .map_err(|e| format!("发送 progress 事件失败: {e}"))?;
        }

        "completed" => {
            app.emit("deepseek-task-completed", &event)
                .map_err(|e| format!("发送 completed 事件失败: {e}"))?;
        }

        "error" => {
            app.emit("deepseek-task-error", &event)
                .map_err(|e| format!("发送 error 事件失败: {e}"))?;
        }

        _ => {
            app.emit("deepseek-task-unknown", &event)
                .map_err(|e| format!("发送 unknown 事件失败: {e}"))?;
        }
    }

    Ok(())
}
```

# 十八、执行任务 Command

```rust name=src-tauri/src/commands.rs
use std::time::Instant;

use serde::{Deserialize, Serialize};
use tauri::AppHandle;
use uuid::Uuid;

use crate::deepseek::{ensure_deepseek_window, inject_task};

#[derive(Debug, Deserialize)]
pub struct ExecuteTaskRequest {
    pub prompt: String,

    #[serde(default = "default_timeout")]
    pub timeout_ms: u64,
}

fn default_timeout() -> u64 {
    180_000
}

#[derive(Debug, Serialize)]
pub struct ExecuteTaskResponse {
    pub success: bool,
    pub prompt: String,
    pub result: Option<String>,
    pub error: Option<String>,
    pub message: Option<String>,
    pub elapsed_ms: u64,
}

#[tauri::command]
pub async fn execute_deepseek_task(
    app: AppHandle,
    request: ExecuteTaskRequest,
) -> Result<ExecuteTaskResponse, String> {
    let started_at = Instant::now();

    if request.prompt.trim().is_empty() {
        return Ok(ExecuteTaskResponse {
            success: false,
            prompt: request.prompt,
            result: None,
            error: Some("MISSING_PROMPT".to_string()),
            message: Some("提示词不能为空".to_string()),
            elapsed_ms: 0,
        });
    }

    if request.prompt.len() > 100_000 {
        return Ok(ExecuteTaskResponse {
            success: false,
            prompt: request.prompt,
            result: None,
            error: Some("PROMPT_TOO_LONG".to_string()),
            message: Some("提示词长度不能超过 100000 个字符".to_string()),
            elapsed_ms: 0,
        });
    }

    let _window = ensure_deepseek_window(&app)?;

    let task_id = Uuid::new_v4().to_string();

    inject_task(
        &app,
        &task_id,
        &request.prompt,
    )
    .await?;

    /*
     * 这里需要等待 receive_deepseek_page_event 收到：
     *
     * {
     *   "type": "completed",
     *   "taskId": "...",
     *   "result": "..."
     * }
     *
     * 实际项目中建议通过：
     * - tokio::sync::oneshot
     * - AppState 中的任务管理器
     * - task_id 映射 sender
     *
     * 将页面事件和当前 Command 关联起来。
     */

    Ok(ExecuteTaskResponse {
        success: true,
        prompt: request.prompt,
        result: None,
        error: None,
        message: Some("任务已提交，等待页面返回结果".to_string()),
        elapsed_ms: started_at.elapsed().as_millis() as u64,
    })
}
```

这里的 `Uuid` 依赖：

# 十九、Rust 中真正等待完成事件

上面的 `execute_deepseek_task` 只是完成了“注入并提交”。

实际要让它等待最终结果，需要在 Tauri 状态中保存任务发送器。

## 任务状态

```rust name=src-tauri/src/main.rs
use std::collections::HashMap;
use std::sync::Arc;

use tokio::sync::{oneshot, Mutex};

use crate::models::DeepSeekPageEvent;

pub struct TaskManager {
    pub tasks: Mutex<
        HashMap<String, oneshot::Sender<DeepSeekPageEvent>>
    >,
}

impl TaskManager {
    pub fn new() -> Self {
        Self {
            tasks: Mutex::new(HashMap::new()),
        }
    }
}
```

注册状态：

```rust name=src-tauri/src/main.rs
use std::sync::Arc;

fn main() {
    let task_manager = Arc::new(TaskManager::new());

    tauri::Builder::default()
```

然后：

```rust
#[tauri::command]
pub async fn execute_deepseek_task(
    app: AppHandle,
    manager: State<'_, Arc<TaskManager>>,
    request: ExecuteTaskRequest,
) -> Result<ExecuteTaskResponse, String> {
    let task_id = Uuid::new_v4().to_string();

    let (sender, receiver) = tokio::sync::oneshot::channel();

    {
        let mut tasks = manager.tasks.lock().await;
        tasks.insert(task_id.clone(), sender);
    }

    inject_task(
        &app,
        &task_id,
        &request.prompt,
    )
    .await?;

    let event = tokio::time::timeout(
        Duration::from_millis(request.timeout_ms),
        receiver,
    )
    .await
    .map_err(|_| "DeepSeek 回复超时".to_string())?
    .map_err(|_| "DeepSeek 任务通道已关闭".to_string())?;

    if event.event_type == "completed" {
        return Ok(ExecuteTaskResponse {
            success: true,
            prompt: request.prompt,
            result: event.result,
            error: None,
            message: None,
            elapsed_ms: 0,
        });
    }

    Ok(ExecuteTaskResponse {
        success: false,
        prompt: request.prompt,
        result: None,
        error: event.error,
        message: event.message,
        elapsed_ms: 0,
    })
}
```

页面事件处理：

```rust
#[tauri::command]
pub async fn receive_deepseek_page_event(
    manager: State<'_, Arc<TaskManager>>,
    payload: PageEventRequest,
) -> Result<(), String> {
    let event: DeepSeekPageEvent =
        serde_json::from_str(&payload.event)
            .map_err(|e| format!("解析页面事件失败: {e}"))?;

    if event.event_type != "completed"
        && event.event_type != "error"
    {
        return Ok(());
    }

    let mut tasks = manager.tasks.lock().await;

    if let Some(sender) = tasks.remove(&event.task_id) {
        let _ = sender.send(event);
    }

    Ok(())
}
```

需要注意：

- `progress` 事件可以通过 Tauri Event 发给 Vue；
- `completed` 和 `error` 事件用于结束 Rust Command；
- 任务结束后必须从 `HashMap` 删除任务；
- 超时后也必须清理任务；
- 必须使用 `task_id` 防止旧任务回传污染新任务。

# 二十、Vue 监听任务进度

```vue name=src/App.vue
<script setup lang="ts">
import { onMounted, onUnmounted, ref } from 'vue'
import { invoke } from '@tauri-apps/api/core'
import { listen, type UnlistenFn } from '@tauri-apps/api/event'

const prompt = ref('')
const result = ref('')
const progressText = ref('')
const status = ref('IDLE')
const loading = ref(false)
const errorMessage = ref('')

let unlistenProgress: UnlistenFn | undefined

onMounted(async () => {
  unlistenProgress = await listen<{
    text?: string
    generating?: boolean
    stableCount?: number
  }>('deepseek-task-progress', (event) => {
    progressText.value = event.payload.text || ''
    status.value = event.payload.generating
      ? 'RUNNING'
      : 'EXTRACTING'
  })
})

onUnmounted(() => {
  unlistenProgress?.()
})

async function executeTask() {
  if (!prompt.value.trim() || loading.value) {
    return
  }

  loading.value = true
  result.value = ''
  errorMessage.value = ''
  status.value = 'PREPARING'

  try {
    const response = await invoke<{
      success: boolean
      result?: string
      error?: string
      message?: string
    }>('execute_deepseek_task', {
      request: {
        prompt: prompt.value,
        timeoutMs: 180000
      }
    })

    if (response.success) {
      result.value = response.result || ''
      status.value = 'COMPLETED'
    } else {
      errorMessage.value =
        response.message ||
        response.error ||
        '任务执行失败'

      status.value = 'FAILED'
    }
  } catch (error) {
    errorMessage.value = String(error)
    status.value = 'FAILED'
  } finally {
    loading.value = false
  }
}
</script>

<template>
  <main>
    <h1>DeepSeek 网页任务执行</h1>

    <textarea
      v-model="prompt"
      :disabled="loading"
      rows="14"
      placeholder="输入需要交给 DeepSeek 网页执行的提示词"
    />

    <button
      :disabled="loading || !prompt.trim()"
      @click="executeTask"
    >
      {{ loading ? '执行中...' : '执行提示词' }}
    </button>

    <p>状态：{{ status }}</p>

    <section v-if="progressText">
      <h2>当前回复</h2>
      <pre>{{ progressText }}</pre>
    </section>

    <section v-if="result">
      <h2>最终结果</h2>
      <pre>{{ result }}</pre>
    </section>

    <p v-if="errorMessage" style="color: red">
      {{ errorMessage }}
    </p>
  </main>
</template>
```

# 二十一、是否必须使用远程页面 IPC

上面的注入脚本使用：

```javascript
window.__TAURI__.core.invoke(...)
```

这要求 DeepSeek 远程页面能够访问 Tauri IPC。

Tauri 默认会限制远程页面访问本地 IPC，必须显式配置远程域名权限。建议只允许：

```text
https://chat.deepseek.com
```

并且只开放一个用途明确的 Command：

```text
receive_deepseek_page_event
```

不要给远程 DeepSeek 页面开放：

```text
文件系统权限
Shell 权限
进程权限
窗口创建权限
任意 URL 权限
```

---

# 二十二、远程页面 IPC 的安全问题

如果 DeepSeek 页面被允许调用 Tauri IPC，那么页面内的 JavaScript 理论上可以调用你开放的 Command。

因此：

```rust
#[tauri::command]
pub fn receive_deepseek_page_event(...) {
    // 必须只允许接收结构化事件
}
```

这个 Command 中不要执行：

```text
任意 Shell 命令
任意文件路径
任意脚本
任意 URL
任意数据库操作
```

建议只接受：

```rust
struct PageEventRequest {
    event: String,
}
```

并且反序列化为严格的数据结构：

```rust
let event: DeepSeekPageEvent =
    serde_json::from_str(&payload.event)?;
```

不要直接执行页面传入的内容。

# 二十三、注入脚本中的关键细节

## 1. 使用原生 setter

只写：

```javascript
input.value = prompt
```

有时不会触发 Vue、React 或其他前端框架的状态更新。

应使用：

```javascript
const setter = Object.getOwnPropertyDescriptor(
    HTMLTextAreaElement.prototype,
    'value'
)?.set;

setter.call(input, prompt);
```

然后补充：

```javascript
input.dispatchEvent(new InputEvent('input', {
    bubbles: true
}));
```

---

## 2. 优先点击发送按钮

不要完全依赖：

```javascript
Enter
```

因为 Enter 可能被网页解释为换行。

推荐：

```text
查找发送按钮并点击
找不到发送按钮时再使用 Enter
```

---

## 3. 不能立刻获取结果

提交后立即读取回复，可能获取到：

- 旧回复；
- 空字符串；
- 正在生成中的不完整内容；
- 用户上一轮的内容。

应至少满足：

```text
文本非空
停止生成按钮消失
文本连续两次不变
```

---

## 4. 使用 `MutationObserver`

DeepSeek 回复是流式更新的，使用：

```javascript
new MutationObserver(...)
```

比固定等待几秒更可靠。

同时建议保留定时器作为兜底：

```javascript
setInterval(checkReply, 1000)
```

---

## 5. 防止脚本重复执行

每次注入前增加：

```javascript
if (window.__DEEPSEEK_TASK_RUNNING__) {
    return;
}

window.__DEEPSEEK_TASK_RUNNING__ = true;
```

任务结束后清理：

```javascript
window.__DEEPSEEK_TASK_RUNNING__ = false;
```

否则重复点击执行按钮可能创建多个 `MutationObserver`。

建议统一放在脚本顶部：

```javascript
const SELECTORS = {

```

后续网页结构变化时，只需要调整这里。

# 二十五、建议先做一个调试脚本

正式实现前，可以先注入以下调试脚本，用于查看 DeepSeek 当前页面结构：

```javascript
(() => {
    const result = {
        url: location.href,
        title: document.title,
        textareas: [],
        contenteditables: [],
        buttons: [],
        markdownElements: []
    };

    document.querySelectorAll('textarea').forEach((element) => {
        result.textareas.push({
            placeholder: element.getAttribute('placeholder'),
            id: element.id,
            className: element.className,
            visible: element.offsetParent !== null
        });
    });

    document
        .querySelectorAll('[contenteditable="true"]')
        .forEach((element) => {
            result.contenteditables.push({
                role: element.getAttribute('role'),
                className: element.className,
                visible: element.offsetParent !== null
            });
        });

    document.querySelectorAll('button').forEach((element) => {
        result.buttons.push({
            text: element.innerText,
            ariaLabel: element.getAttribute('aria-label'),
            title: element.getAttribute('title'),
            className: element.className,
            disabled: element.disabled,
            visible: element.offsetParent !== null
        });
    });

    document
        .querySelectorAll('.ds-markdown, [class*="markdown"]')
        .forEach((element) => {
            result.markdownElements.push({
                text: element.innerText,
                className: element.className
            });
        });

    console.log('[DeepSeek Debug]', result);

    return JSON.stringify(result);
})();
```

这个脚本可以帮助确认：

- 实际输入框是什么元素；
- 发送按钮有什么属性；
- AI 回复使用什么 class；
- 停止生成按钮有什么属性。

网页结构更新后，先重新运行这个调试脚本，再修改选择器。

# 二十七、最终可落地方案

你的场景不需要实现聊天记录，也不需要模拟完整聊天应用，只需要实现一个网页任务执行器：

```text
提示词输入框
  ↓
执行按钮
  ↓
DeepSeek WebView
  ↓
注入提示词
  ↓
网页执行
  ↓
提取最后一条 AI 回复
  ↓
返回最终结果
```

核心 JavaScript 必须包含：

```javascript
1. findInput()
2. setInputValue()
3. findSendButton()
4. submitPrompt()
5. getLastReplyText()
6. hasStopButton()
7. MutationObserver
8. invokeRust()
9. cleanup()
```

其中最关键的是：

```javascript
const setter = Object.getOwnPropertyDescriptor(
    HTMLTextAreaElement.prototype,
    'value'
)?.set;

setter.call(input, prompt);

input.dispatchEvent(new InputEvent('input', {
    bubbles: true
}));
```

以及：

```javascript
if (
    text.length > 0 &&
    !generating &&
    stableCount >= 2
) {
    invokeRust('completed', {
        result: text
    });
}
```

这套方式可以完全移除当前仓库中的：

```text
Node.js
Playwright
Chrome CDP
ensure_chrome.js
```

最终变成：

```text
Vue 3 + Tauri 2 + Rust + Tauri WebView + 注入 JavaScript
```

但需要持续维护 DeepSeek 网页选择器，并遵守网页服务的使用规则，不要绕过验证码、风控或登录保护。
